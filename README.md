# Flight Data Visualizer
*A lightweight 3D visualizer for analyzing KSP flight data.*

## Description
Kerbal Space Program's kOS mod provides plenty of freedom in the way of changing the game the way is played, including data logging and processing. With much of the game's useful and interesting information being in the form of 3D vectors, analyzing flight logs on a spreadsheet proves to be tedious and confusing. This tool serves to quickly intake time-indexed spreadsheet data and convert it for visualization in a controllable 3D environment for better and more understandable analysis for craft design.

## Primary Libraries Used
- numpy
- pandas
- PyQt5
- pyvista & pyvistaqt

## Other
This tool has been primarily designed for usage on Linux through the X11 display protocol.
